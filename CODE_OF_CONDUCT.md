# Code of Conduct

We want SyntaxLab to be a welcoming, practical project for learners and contributors.

Participants are expected to be respectful, assume good intent, give actionable feedback, and focus on the work rather than the person. Harassment, discrimination, personal attacks, and publishing private information are not acceptable.

Project maintainers may remove comments, close issues, or restrict participation when behavior conflicts with these standards. To report a concern, open a private security/contact channel with the repository maintainers.
